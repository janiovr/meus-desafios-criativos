##Desafio Criativo: Simplificando Tarefas e Ganhando Foco com IA
Descrição
Este repositório foi criado para entregar o desafio prático da DIO "Simplificando Tarefas e Ganhando Foco com IA".
A proposta da atividade é exercitar a criação de prompts claros, objetivos e bem estruturados, utilizando intenção, contexto e restrições para orientar uma IA de forma eficiente.
Objetivo do desafio
O objetivo deste desafio é construir um prompt final de maneira organizada, passando por etapas que ajudam a definir:
o que a IA deve gerar
para quem o conteúdo será criado
qual resultado se espera
quais restrições e contexto devem ser considerados
Estrutura do projeto
Este repositório contém os seguintes arquivos:
prompt-final.txt → arquivo com o prompt final desenvolvido no desafio
README.md → descrição do projeto e contexto da entrega
Como visualizar o arquivo .txtPara acessar o conteúdo do desafio:
abra este repositório no GitHub
clique no arquivo prompt-final.txt
visualize o prompt final diretamente pelo navegador
