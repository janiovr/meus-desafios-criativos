Desafio Criativo: Simplificando Tarefas e Ganhando Foco com IADescriçãoEste repositório foi criado para entregar o desafio prático da DIO "Simplificando Tarefas e Ganhando Foco com IA".A proposta da atividade é exercitar a criação de prompts claros, objetivos e bem estruturados, utilizando intenção, contexto e restrições para orientar uma IA de forma eficiente.Objetivo do desafioO objetivo deste desafio é construir um prompt final de maneira organizada, passando por etapas que ajudam a definir:
o que a IA deve gerar
para quem o conteúdo será criado
qual resultado se espera
quais restrições e contexto devem ser considerados
Estrutura do projetoEste repositório contém os seguintes arquivos:
prompt-final.txt → arquivo com o prompt final desenvolvido no desafio
README.md → descrição do projeto e contexto da entrega
Prompt finalQuero que a IA gere um plano de estudos para uma pessoa em transição para a área de tecnologia, com o objetivo de conquistar a primeira vaga em TI.Considere o seguinte contexto: a pessoa está começando em tecnologia, tem interesse em Desenvolvimento Front-end, QA e Suporte Técnico, possui pouco tempo por semana para estudar e precisa de foco em aprendizado prático, portfólio e preparação para entrevistas.O conteúdo deve ter formato de lista por etapas semanais, com linguagem clara, objetiva e motivadora.Evite linguagem excessivamente técnica, respostas vagas e recomendações difíceis de aplicar na prática.Como visualizar o arquivo .txtPara acessar o conteúdo do desafio:
abra este repositório no GitHub
clique no arquivo prompt-final.txt
visualize o prompt final diretamente pelo navegador
